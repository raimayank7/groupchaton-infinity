# GroupChatOn Tools

Files for **infinity.groupchaton.com**, the free tools site of GroupChatOn, served from **assets.infinity.groupchaton.com**.

- `assets/site.css`, `assets/site.js`: design and site script
- `assets/tools/`: one script per tool, plus `kit.js` (shared helpers and the tool list) and `tools.css`
- `assets/pages/`: Blogger pages (Privacy Policy, Disclaimer, Ask for a Tool) that load from here

Every tool runs in the visitor's browser: files are never uploaded.
